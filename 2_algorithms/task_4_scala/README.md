# 2.4 Кратчайший путь в графе алгоритмом Дейкстры

Тема: Алгоритмические задачи  
Язык: Scala  
Ветка: `2_task_4_scala`

## Постановка задачи

Имеется взвешенный ориентированный граф с неотрицательными весами рёбер, а также начальная и конечная вершины. Требуется найти кратчайший путь между ними алгоритмом Дейкстры и вывести не только его длину, но и сам маршрут. Приоритетная очередь, из которой алгоритм извлекает ближайшую вершину, должна быть написана самостоятельно как двоичная куча на массиве; готовые коллекции с приоритетом использовать нельзя.

Входные данные: файл с описанием графа, каждая строка задаёт ребро в виде «вершина вершина вес»; имена начальной и конечной вершин передаются аргументами.

Выходные данные: длина кратчайшего пути, последовательность вершин на этом пути и таблица расстояний до всех достижимых вершин. Если путь не существует, выводится сообщение об этом.

## Запуск программы

```
scalac Dijkstra.scala
scala Dijkstra graph.txt A F
```
