# 4.3 Сетевая игра «угадай число»

Тема: Клиент-серверное взаимодействие  
Язык: OCaml  
Ветка: `4_task_3_ocaml`

## Постановка задачи

Требуется написать сетевую игру. Сервер при подключении клиента загадывает целое число из заданного диапазона, принимает попытки и на каждую отвечает «больше», «меньше» или «угадал»; после победы сообщает количество затраченных попыток и предлагает сыграть ещё раз. Каждому клиенту загадывается своё число, и обслуживание одного клиента не должно мешать остальным, поэтому под каждое соединение создаётся отдельный процесс. Нечисловой ввод обрабатывается как ошибка и не засчитывается за попытку.

Входные данные: порт и границы диапазона задаются при запуске сервера; клиент получает адрес и порт, числа вводятся с клавиатуры.

Выходные данные: ответ сервера на каждую попытку, итог партии с числом попыток; на сервере журнал подключений и результатов.

## Запуск программы

```
ocamlfind ocamlopt -package unix -linkpkg server.ml -o server
./server 9000 1 100
```
