# 1.3 Обедающие философы

Тема: Многопоточность  
Язык: Elixir  
Ветка: `1_task_3_elixir`

## Постановка задачи

Имеется круглый стол, за которым сидят пять философов, между соседями лежат пять вилок. Философ либо думает, либо ест, причём есть он может только тогда, когда взял обе соседние вилки. Требуется смоделировать поведение философов, представив каждого философа и каждую вилку отдельным процессом; процессы взаимодействуют только сообщениями, общей памяти нет. Модель не должна попадать в взаимную блокировку, для этого один из философов берёт вилки в обратном порядке.

Входные данные: время работы модели в секундах и число философов задаются при запуске.

Выходные данные: журнал событий (философ думает, взял вилку, ест, положил вилки) и итоговая таблица: сколько раз поел каждый философ за отведённое время.

## Запуск программы

```
elixir philosophers.exs 5 10
```
