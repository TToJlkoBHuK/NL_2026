# 4.1 Текстовый чат по протоколу TCP

Тема: Клиент-серверное взаимодействие  
Язык: Erlang  
Ветка: `4_task_1_erlang`

## Постановка задачи

Требуется написать сервер и клиент текстового чата, работающие по TCP. Сервер принимает произвольное число подключений; при входе клиент сообщает свой ник, который проверяется на уникальность. Сообщение, отправленное одним участником, доставляется всем остальным вместе с именем отправителя. Каждое соединение обслуживается собственным процессом, а список участников хранит отдельный процесс-диспетчер, к которому процессы обращаются сообщениями. Поддерживаются команды /list и /quit, о входе и выходе участника остальные уведомляются.

Входные данные: порт сервера задаётся при запуске; клиент получает адрес, порт и ник, сообщения вводятся с клавиатуры.

Выходные данные: у каждого клиента — поток сообщений чата с именами отправителей и служебные уведомления; на сервере — журнал подключений и отключений.

## Запуск программы

```
erlc chat_server.erl chat_client.erl
erl -noshell -s chat_server start 9000
```
