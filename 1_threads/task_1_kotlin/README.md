# 1.1 Параллельный подсчёт частоты слов в наборе текстовых файлов

Тема: Многопоточность  
Язык: Kotlin  
Ветка: `1_task_1_kotlin`

## Постановка задачи

Имеется каталог с текстовыми файлами. Требуется подсчитать, сколько раз каждое слово встречается во всех файлах вместе, и вывести десять самых частых слов. Подсчёт должен выполняться в несколько потоков: файлы распределяются между потоками, каждый поток считает слова только в своих файлах и строит собственный словарь, после чего словари объединяются в общий. Доступ к общему словарю должен быть защищён от одновременной записи.

Входные данные: путь к каталогу с файлами и число потоков задаются аргументами командной строки. Словом считается непрерывная последовательность букв и цифр, регистр не учитывается.

Выходные данные: таблица из десяти слов с количеством вхождений, общее количество обработанных слов и время работы. Для сравнения тот же подсчёт выполняется в один поток, оба времени печатаются рядом.

## Запуск программы

```
kotlinc Main.kt -include-runtime -d app.jar
java -jar app.jar files/ 4
```
