# 4.4 Минимальный HTTP-сервер на сокетах

Тема: Клиент-серверное взаимодействие  
Язык: Groovy  
Ветка: `4_task_4_groovy`

## Постановка задачи

Требуется написать HTTP-сервер поверх обычного сокета, без веб-фреймворков и готовых серверов. Сервер сам разбирает строку запроса и заголовки, определяет метод и путь и формирует ответ: по обычному пути отдаёт файл из указанного каталога с подходящим заголовком Content-Type, по пути /stats — страницу со счётчиками обработанных запросов, на несуществующий путь возвращает 404, на неподдерживаемый метод — 405. Каждое соединение обрабатывается в отдельном потоке, выход за пределы каталога запрещён. Требуется также клиент, отправляющий запрос и печатающий ответ вместе с заголовками.

Входные данные: порт и каталог с файлами задаются при запуске сервера; клиенту передаётся адрес запроса.

Выходные данные: ответы сервера в браузере или в клиенте, журнал запросов в консоли сервера (время, метод, путь, код ответа, размер).

## Запуск программы

```
groovy HttpServer.groovy 8080 www/
```
