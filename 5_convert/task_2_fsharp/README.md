# 5.2 Преобразование JSON в XML

Тема: Конвертация данных из одного формата в другой  
Язык: F#  
Ветка: `5_task_2_fsharp`

## Постановка задачи

Имеется файл в формате JSON. Требуется разобрать его в дерево, состоящее из объектов, массивов, строк, чисел и литералов true, false и null, а затем вывести это дерево в виде XML. Разбор выполняется методом рекурсивного спуска, готовые парсеры не используются. Ключи объекта становятся именами элементов, элементы массива получают одинаковые имена с атрибутом-номером, недопустимые в именах символы заменяются, а символы <, >, & и кавычки экранируются. Вложенность передаётся отступами.

Входные данные: имя входного json-файла и имя выходного файла передаются аргументами.

Выходные данные: XML-документ с отступами и число обработанных узлов. При ошибке разбора выводится позиция в файле и ожидаемый символ.

## Запуск программы

```
dotnet fsi json2xml.fsx data.json out.xml
```
