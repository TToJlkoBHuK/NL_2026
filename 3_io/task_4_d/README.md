# 3.4 Разрезание файла на части и сборка обратно

Тема: Ввод/вывод в консоль и файл  
Язык: D  
Ветка: `3_task_4_d`

## Постановка задачи

Имеется файл произвольного размера. Требуется разрезать его на части заданного размера и уметь собрать обратно. При разрезании для каждой части вычисляется контрольная сумма, а рядом создаётся текстовый файл описания, в котором записаны имя исходного файла, его размер, список частей, их размеры и контрольные суммы. При сборке программа читает файл описания, соединяет части в правильном порядке и проверяет контрольные суммы. Чтение и запись выполняются блоками, файл целиком в память не загружается.

Входные данные: режим (split или join), имя файла и размер части в байтах передаются аргументами.

Выходные данные: в режиме split — файлы частей вида name.part001 и файл описания; в режиме join — восстановленный файл и отчёт о проверке, включая сообщение о потерянной или повреждённой части.

## Запуск программы

```
dmd -O split.d
./split split big.bin 1048576
```
