# 3.2 Консольный менеджер задач с хранением в файле

Тема: Ввод/вывод в консоль и файл  
Язык: Lua  
Ветка: `3_task_2_lua`

## Постановка задачи

Требуется написать консольную программу для ведения списка дел, которая хранит данные в обычном текстовом файле. Программа работает в цикле и принимает команды: add — добавить задачу, list — показать список, done — отметить задачу выполненной, del — удалить задачу, find — найти задачи по подстроке, help и exit. Список читается из файла при запуске и перезаписывается после каждого изменения, поэтому данные не теряются между запусками. Неверные команды и неверные номера задач не должны приводить к аварийному завершению.

Входные данные: имя файла со списком передаётся аргументом (по умолчанию tasks.txt), команды вводятся пользователем с клавиатуры.

Выходные данные: список задач в виде выровненной таблицы (номер, отметка о выполнении, дата добавления, текст), подтверждения выполненных команд и сообщения об ошибках ввода.

## Запуск программы

```
lua todo.lua tasks.txt
```
