# 2.2 Символьное дифференцирование выражений

Тема: Алгоритмические задачи  
Язык: Scheme  
Ветка: `2_task_2_scheme`

## Постановка задачи

Имеется арифметическое выражение от одной переменной, записанное списком, например (+ (* 3 (^ x 2)) (* 2 x)). Требуется построить производную этого выражения по переменной x и упростить результат. Выражение представляет собой дерево, поэтому и дифференцирование, и упрощение выполняются рекурсивным обходом этого дерева. Поддерживаются сложение, вычитание, умножение, деление и возведение в целую степень. При упрощении убираются нулевые слагаемые и единичные множители, сворачиваются числовые подвыражения.

Входные данные: выражение читается из файла или вводится с консоли в виде списка.

Выходные данные: производная в неупрощённом и упрощённом виде, а также значение производной в точке, если точка задана.

## Запуск программы

```
guile deriv.scm expr.txt
```
