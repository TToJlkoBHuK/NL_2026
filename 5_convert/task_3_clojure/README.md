# 5.3 Преобразование Markdown в HTML

Тема: Конвертация данных из одного формата в другой  
Язык: Clojure  
Ветка: `5_task_3_clojure`

## Постановка задачи

Имеется файл с текстом в разметке Markdown. Требуется преобразовать его в готовую HTML-страницу. Поддерживается подмножество разметки: заголовки шести уровней, маркированные и нумерованные списки, жирный и курсивный текст, код внутри строки, блоки кода, ссылки, цитаты, горизонтальные разделители и обычные абзацы. Разбор ведётся построчно с учётом того, что списки и блоки кода занимают несколько строк подряд. Спецсимволы HTML экранируются, чтобы текст не ломал разметку страницы.

Входные данные: имя входного md-файла и имя выходного файла передаются аргументами.

Выходные данные: html-файл с заголовком, минимальными стилями и преобразованным текстом; в консоли статистика: сколько заголовков, списков, ссылок и блоков кода обработано.

## Запуск программы

```
clojure -M md2html.clj doc.md doc.html
```
