# 5.4 Преобразование XML в CSV

Тема: Конвертация данных из одного формата в другой  
Язык: Lisp  
Ветка: `5_task_4_lisp`

## Постановка задачи

Имеется файл XML, содержащий набор однотипных записей, например список книг, у которых частично совпадает набор вложенных тегов. Требуется разобрать документ и выгрузить записи в таблицу CSV. Разбор XML пишется самостоятельно: документ превращается во вложенные списки, поддерживаются атрибуты, одиночные теги и комментарии. Затем программа проходит по всем записям, собирает полный набор имён полей, формирует из него заголовок таблицы, а для отсутствующих у записи полей оставляет пустые ячейки. Значения с запятыми, кавычками и переводами строк экранируются по правилам CSV.

Входные данные: имя входного xml-файла, имя выходного файла и имя тега, который считается записью, передаются аргументами.

Выходные данные: файл CSV с заголовком, количество обработанных записей и список найденных полей.

## Запуск программы

```
sbcl --script xml2csv.lisp books.xml books.csv book
```
