# 3.3 Шестнадцатеричный дамп файла и обратная сборка

Тема: Ввод/вывод в консоль и файл  
Язык: Nim  
Ветка: `3_task_3_nim`

## Постановка задачи

Имеется произвольный файл, в том числе двоичный. Требуется вывести его содержимое в виде шестнадцатеричного дампа: в каждой строке смещение от начала файла, шестнадцать байт в шестнадцатеричном виде и те же байты в текстовом виде, где непечатаемые символы заменены точкой. Дамп одновременно выводится на экран и записывается в текстовый файл. Требуется также обратная операция: собрать двоичный файл из ранее сохранённого дампа и проверить, что он побайтово совпадает с исходным.

Входные данные: режим работы (dump или restore), имя входного и имя выходного файла передаются аргументами командной строки.

Выходные данные: в режиме dump — дамп на экране и в файле, размер файла в байтах; в режиме restore — восстановленный файл и результат побайтового сравнения с оригиналом.

## Запуск программы

```
nim c -d:release hexdump.nim
./hexdump dump input.bin input.hex
```
