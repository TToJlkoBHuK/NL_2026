# 2.1 Решение судоку методом перебора с возвратом

Тема: Алгоритмические задачи  
Язык: Haskell  
Ветка: `2_task_1_haskell`

## Постановка задачи

Имеется поле судоку 9x9, часть клеток заполнена цифрами от 1 до 9, остальные пустые. Требуется заполнить пустые клетки так, чтобы в каждой строке, в каждом столбце и в каждом квадрате 3x3 все девять цифр встречались ровно по одному разу. Задача решается рекурсивно, перебором с возвратом: цифра ставится в первую свободную клетку, проверяется на допустимость, после чего решение продолжается для оставшегося поля; если ни одна цифра не подходит, происходит откат на шаг назад.

Входные данные: файл с полем: девять строк по девять символов, пустая клетка обозначается точкой или нулём.

Выходные данные: решённое поле в виде таблицы и количество рассмотренных вариантов. Если решения не существует, выводится соответствующее сообщение.

## Запуск программы

```
ghc -O2 Sudoku.hs
./Sudoku puzzle.txt
```
