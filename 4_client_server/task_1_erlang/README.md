# 4.1 Текстовый чат по протоколу TCP

Тема: Клиент-серверное взаимодействие  
Язык: Erlang  
Ветка: `4_task_1_erlang`

## Постановка задачи

Требуется написать сервер и клиент текстового чата, работающие по TCP. Сервер принимает произвольное число подключений; при входе клиент сообщает свой ник. Сообщение, отправленное одним участником, доставляется всем остальным вместе с именем отправителя. Каждое соединение обслуживается собственным процессом, а список участников хранит отдельный процесс-диспетчер, к которому процессы обращаются сообщениями. Поддерживаются команды /list и /quit, о входе и выходе участника остальные уведомляются.

Входные данные: порт сервера задаётся при запуске; клиент получает адрес и порт, ник и сообщения вводятся с клавиатуры.

Выходные данные: у каждого клиента — поток сообщений чата с именами отправителей и служебные уведомления; на сервере — журнал подключений и отключений.

## Запуск программы

```
erlc chat_server.erl chat_client.erl

# первый терминал
erl -noshell -pa . -eval 'chat_server:start(9000)'

# второй и третий терминалы
erl -noshell -pa . -eval 'chat_client:start("127.0.0.1", 9000)'
```
