# 1.2 Сегментное решето Эратосфена на пуле потоков

Тема: Многопоточность  
Язык: Rust  
Ветка: `1_task_2_rust`

## Постановка задачи

Имеется отрезок натуральных чисел от 1 до N. Требуется найти все простые числа на этом отрезке. Отрезок разбивается на блоки одинаковой длины, блоки раздаются рабочим потокам через канал, каждый поток просеивает свой блок и отправляет результат обратно. Главный поток собирает ответы от всех потоков и сводит их вместе. Число потоков задаётся пользователем и не зависит от числа блоков.

Входные данные: верхняя граница N и число потоков задаются аргументами командной строки.

Выходные данные: количество найденных простых чисел, последние десять из них и время работы. Для проверки результат сравнивается с обычным однопоточным решетом.

## Запуск программы

```
rustc -O main.rs
./main 10000000 4
```
