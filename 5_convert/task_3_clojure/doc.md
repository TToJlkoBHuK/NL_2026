# Отчёт по лабораторной работе

Это **пробный** документ для проверки конвертера. Он содержит *курсив*,
инлайн-код `printf` и ссылку на [сайт языка](https://clojure.org).

## Что сделано

- разобран подмножество Markdown
- заголовки шести уровней
- списки двух видов

1. первый пункт
2. второй пункт
3. третий пункт

> Цитата занимает отдельный блок
> и может быть многострочной.

---

## Пример кода

```
(defn hello [name]
  (println "привет," name))
```

Обычный абзац после блока кода. Символы < и > экранируются.
