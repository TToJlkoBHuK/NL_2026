# 1.4 Конвейер производитель-потребитель для разбора журналов

Тема: Многопоточность  
Язык: Ruby  
Ветка: `1_task_4_ruby`

## Постановка задачи

Имеется каталог с файлами журналов приложения. Требуется обработать их по схеме «производитель-потребитель»: несколько потоков-читателей читают файлы построчно и кладут строки в общую очередь, несколько потоков-обработчиков забирают строки из очереди, разбирают их и накапливают общую статистику. Очередь должна иметь ограниченный размер, чтобы читатели не переполняли память, а обработчики должны корректно завершаться после того, как прочитаны все файлы. Доступ к общей статистике защищается мьютексом.

Входные данные: каталог с журналами, число читателей и число обработчиков задаются аргументами командной строки.

Выходные данные: сводный отчёт: количество прочитанных строк, распределение записей по уровням INFO, WARN и ERROR, пять самых частых сообщений и время работы.

## Запуск программы

```
ruby pipeline.rb logs/ 2 4
```
