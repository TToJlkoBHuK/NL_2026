# 2.3 Расстояние Левенштейна с восстановлением цепочки правок

Тема: Алгоритмические задачи  
Язык: Zig  
Ветка: `2_task_3_zig`

## Постановка задачи

Имеются две строки. Требуется найти расстояние Левенштейна между ними, то есть наименьшее число операций вставки, удаления и замены одного символа, которые переводят первую строку во вторую, и дополнительно вывести саму последовательность этих операций. Расстояние вычисляется методом динамического программирования: строится матрица, где каждая ячейка зависит от трёх соседних. Цепочка правок восстанавливается обратным проходом по заполненной матрице от правого нижнего угла к левому верхнему.

Входные данные: две строки задаются аргументами командной строки.

Выходные данные: значение расстояния, пошаговый список операций с указанием позиции и символа, а для коротких строк ещё и сама матрица.

## Запуск программы

```
zig run levenshtein.zig -- kitten sitting
```
