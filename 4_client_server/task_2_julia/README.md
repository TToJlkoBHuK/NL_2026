# 4.2 Сетевое хранилище пар ключ-значение

Тема: Клиент-серверное взаимодействие  
Язык: Julia  
Ветка: `4_task_2_julia`

## Постановка задачи

Требуется написать сервер, хранящий пары «ключ-значение» в памяти, и клиент к нему. Обмен идёт по TCP простым текстовым протоколом: SET ключ значение, GET ключ, DEL ключ, KEYS, QUIT; на каждую команду сервер отвечает одной строкой. Сервер должен обслуживать нескольких клиентов одновременно, каждое соединение обрабатывается независимо, а доступ к общему словарю защищается блокировкой. Некорректная команда не должна разрывать соединение, на неё возвращается сообщение об ошибке.

Входные данные: порт сервера задаётся при запуске; клиент получает адрес и порт, команды вводятся с клавиатуры.

Выходные данные: ответы сервера (OK, значение по ключу, NOT FOUND, список ключей, ERR с пояснением) и журнал команд в консоли сервера.

## Запуск программы

```
julia kv_server.jl 9000
julia kv_client.jl 127.0.0.1 9000
```
