# 3.1 Разбор журнала веб-сервера и формирование отчёта

Тема: Ввод/вывод в консоль и файл  
Язык: Perl  
Ветка: `3_task_1_perl`

## Постановка задачи

Имеется файл журнала веб-сервера в формате common log. Требуется прочитать его построчно, выделить из каждой записи адрес клиента, дату, метод, запрошенный путь, код ответа и размер ответа, после чего собрать по этим данным статистику. Условие отбора записей (например, только ответы с кодами 4xx) программа запрашивает у пользователя в консоли. Строки, которые не удалось разобрать, не должны прерывать работу: они считаются отдельно и попадают в отчёт.

Входные данные: путь к файлу журнала и имя файла отчёта передаются аргументами; условие отбора вводится с клавиатуры.

Выходные данные: на экран краткая сводка, в файл отчёта подробная: общее число записей, распределение по кодам ответа, десять самых активных адресов, десять самых запрашиваемых страниц и суммарный объём переданных данных.

## Запуск программы

```
perl make_log.pl access.log 20000
perl loganalyzer.pl access.log report.txt
```
