# 5.1 Преобразование CSV в JSON

Тема: Конвертация данных из одного формата в другой  
Язык: Swift  
Ветка: `5_task_1_swift`

## Постановка задачи

Имеется файл в формате CSV, первая строка которого содержит имена столбцов. Требуется преобразовать его в JSON — массив объектов, где ключами служат имена столбцов, а значениями соответствующие ячейки строки. Разбор CSV должен быть написан самостоятельно и учитывать поля в кавычках, запятые и переводы строк внутри таких полей, а также удвоенные кавычки как способ записать кавычку. Готовые средства разбора и сериализации не используются. Значения, похожие на числа и на true, false, null, записываются без кавычек, остальные как строки с экранированием спецсимволов.

Входные данные: имя входного csv-файла, имя выходного файла и символ-разделитель передаются аргументами.

Выходные данные: файл JSON с отступами и количество преобразованных записей. При нарушении формата выводится сообщение с номером строки и позицией.

## Запуск программы

```
swiftc -O csv2json.swift
./csv2json data.csv out.json
```
